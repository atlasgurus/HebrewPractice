# Hebrew Practice — Next.js app

This is the application. For setup, build, and usage instructions see the
[main README](../README.md) at the repository root.

Quick start:

```bash
npm install
cp .env.local.example .env.local   # add your API keys
npm run dev                        # http://localhost:3000
```

Environment variables are documented in [`.env.local.example`](.env.local.example).
